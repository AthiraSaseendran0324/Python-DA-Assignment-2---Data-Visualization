# Python-DA-Assignment-2---Data-Visualization

##  About
Thi assignment focuses on data cleaning and data visualization using Python. The Seaborn Taxis dataset is used to explore taxi trips, fare distributions, and relationships between numerical variables.

##  Objectives
- Load and explore the Taxis dataset.
- Identify and handle missing values.
- Create visualizations using Matplotlib and Seaborn.
- Analyze taxi fares, trip distances, payment methods, and pickup boroughs.
- Understand relationships between numerical variables using a correlation matrix.

##  Dataset
- **Dataset:** Taxis
- **Source:** Seaborn built-in dataset
- **Rows used:** 650 (subset of the original dataset)
- **Libraries:** Seaborn and Pandas

The dataset contains information about taxi trips, including pickup time, distance, fare, tip, tolls, payment method, and pickup location.

##  Technologies Used
- **Python**
- **Pandas** – Data manipulation and cleaning
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical visualization
- **Google Colab** – Notebook environment

##  Data Cleaning
- Checked the dataset for missing values.
- Handled missing values using appropriate methods.
- Used mode imputation for categorical columns where appropriate.
- Removed selected rows containing multiple missing location details.

##  Visualizations

### Matplotlib
1. **Line Chart:** Fare over time.
2. **Bar Chart:** Total fare by pickup borough.
3. **Pie Chart:** Trips by payment method.
4. **Histogram:** Distribution of taxi trip distances.
5. **Box Plot:** Tip distribution by pickup borough.

### Seaborn
6. **Count Plot:** Number of trips by pickup borough.
7. **Scatter Plot:** Relationship between distance and fare.
8. **Heatmap:** Correlation between distance, fare, tip, tolls, and total.
9. **Pair Plot:** Pairwise relationships between distance, fare, tip, and total, grouped by pickup zone.
10. **Violin Plot:** Fare distribution by payment method.

##  Key Learnings
- Handling missing values in a dataset.
- Using Pandas to select and organize data.
- Creating different types of visualizations.
- Understanding distributions and correlations.
- Exploring relationships between taxi trip variables.
